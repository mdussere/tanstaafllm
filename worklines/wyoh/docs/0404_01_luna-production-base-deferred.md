# Step 4 decision — production base deferred pending physical Luna

**Status:** completed with a defer outcome, 2026-09-26

No physical Luna target is reachable in the configured environment. The only administered device is `luna-pi`, a Raspberry Pi 4 reference board. Its Debian/Sway result is useful for the IPC fixture but cannot answer Luna's delivered OS, RAM, display rotation, DRM/KMS, Mesa/Panfrost/Vulkan, controller mapping, stock frontend, boot/recovery path, or resource budget.

Therefore no production base is selected. The current pre-hardware order remains unmodified, version-pinned Sway IPC first; a thin mediator/adapter only upon demonstrated excess authority or a missing Luna semantic; extension/fork or another base only upon target evidence. Before replacing or flashing anything on Luna, rerun the Step 4 inventory and stock-stack/recovery checklist, then execute the fixture where safe.

This is a defer decision, not a claim that Sway is compatible with Luna.
